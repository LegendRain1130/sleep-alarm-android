# Sleep Alarm Android

根据夜间手机熄屏时间安排起床闹铃的 Android 应用。支持 Android 8.0（API 26）及以上。

## 使用方式

1. 在“闹铃设置”中设定监测开始、结束时间和睡眠时长（1–1440 分钟），可选系统闹铃铃声。
2. 开启“夜间计划”。Android 12 / 12L 如提示缺少“闹钟和提醒”权限，请允许后返回应用。
3. 窗口内熄屏时，从该时刻起按睡眠时长安排闹铃；窗口开始时已经熄屏，也会立即安排。
4. 亮屏即取消尚未响起的预约，锁定状态下也一样。仍在窗口内时，下一次熄屏会重新计时。
5. 响铃时，点锁屏页或闹铃通知上的“停止闹铃”可直接停止声音和振动。锁屏全屏提醒由系统权限控制。应用内也可停铃，正式闹铃最长响两分钟。
6. 关闭夜间计划会取消预约，并停止监测和响铃。

窗口支持跨午夜，开始和结束相同表示全天监测。**窗口结束后，已经预约的闹铃仍会响。** 例如监测时段为 23:30–08:00、睡眠时长为 7 小时，凌晨 02:00 熄屏后会安排 09:00 的闹铃。08:00 之后仍可通过亮屏撤销这次预约，下一次预约需等到新的监测窗口。

## 0.1.3

- 监测结束后保留已预约的闹铃。亮屏立即撤销尚未响起的预约。
- 可在锁屏页和系统通知上直接停止响铃。
- 首页突出预计响铃时间，集中显示监测时段、睡眠时长和铃声。试响和调试提示仅用于调试版。

## 构建与检查

使用 JDK 21、Android SDK Platform 36.1、Build Tools 36.0.0。项目包含 Gradle Wrapper。

```shell
# Windows
.\gradlew.bat testDebugUnitTest lintDebug assembleDebug

# macOS / Linux
./gradlew testDebugUnitTest lintDebug assembleDebug
```

在 Android Studio 配置 SDK，或通过 `ANDROID_HOME` / 本地 `local.properties` 指定路径。调试 APK 位于 `app/build/outputs/apk/debug/app-debug.apk`。不要提交本地 SDK 路径、签名密钥或缓存。

回归测试覆盖时间窗口、跨午夜、夏令时、窗口结束后保留预约、亮屏立即撤销、过期广播及铃声回退。GitHub Actions 在推送和拉取请求时执行单元测试、Lint 和调试构建，保存 APK 与检查报告。设备验收步骤见 [docs/TESTING.md](docs/TESTING.md)。

## 限制与后续方向

- 通知、来电和主动操作造成的亮屏均会撤销尚未响起的预约。
- 锁屏提醒形式由 Android 的通知设置、全屏提醒权限和锁屏状态决定。允许闹铃通知后，也可在其“停止闹铃”按钮上直接停铃。
- 厂商省电策略可能影响后台服务。建议允许通知，将应用电池策略设为“不限制”；系统强行停止后，需要重新打开并保存计划。
- 关机期间无法响铃；开机时已过期的预约会清除。所有铃声均不可用时只保留振动；系统音量与勿扰设置仍影响提醒。
- 当前以测试为主。单元测试和编译检查不能替代真机锁屏、重启和省电模式验收。
- 后续方向：加速度传感器、充电状态识别、穿戴设备睡眠监测。
