# Sleep Alarm Android

根据夜间手机熄屏时间安排起床闹铃的 Android 应用。支持 Android 8.0（API 26）及以上。

## 使用方式

1. 设置夜间开始、结束时间及睡眠时长（1–1440 分钟），可选择自定义铃声。
2. 点击“保存设置并安排夜间计划”。Android 12 / 12L 如提示缺少“闹钟和提醒”权限，请允许后返回，再次保存。
3. 窗口内熄屏时，从该时刻起按睡眠时长安排闹铃；窗口开始时已经熄屏，也会立即安排。
4. 短暂亮屏后在 20 秒内再次熄屏，保留原闹铃。解锁或持续亮屏 20 秒会取消，等待下一次熄屏重新计时。
5. 可通过通知或应用内按钮停止响铃，最长响铃两分钟。关闭计划会取消预约并停止监测、响铃。

窗口支持跨午夜；开始和结束相同表示全天监测。**窗口结束会取消尚未响起的闹铃**，请将结束时间设在预计起床时间之后。例如 23:30–12:00、睡眠 420 分钟时，凌晨 01:00 熄屏会安排 08:00 的闹铃。

## 0.1.2 代码修复

- 夜间开始时已经熄屏也会安排闹铃。
- 保存预约和亮屏宽限状态，服务重建、重复熄屏不再推迟起床时间，重建后解锁仍可取消。
- 修复凌晨调度跳过当晚的问题；统一跨午夜、全天窗口和夏令时边界。
- 关闭后迟到广播不再开启计划；修改窗口会同步停止不再适用的监测。
- 补齐 Android 12 / 12L 精确闹铃权限检查；缺少权限时明确提示，不再静默降级。
- 开机恢复未来预约；时间、时区改变或应用更新后重排窗口；拒绝已取消或被替换的闹铃广播。
- 自定义铃声失效或准备超时，依次尝试默认闹铃、通知及来电铃声；释放失败播放器并忽略停止后的旧回调。
- 修复时长乘法溢出风险、系统栏遮挡，正式构建关闭调试通知。

## 构建与检查

使用 JDK 21、Android SDK Platform 36.1、Build Tools 36.0.0。项目包含 Gradle Wrapper。

```shell
# Windows
.\gradlew.bat testDebugUnitTest lintDebug assembleDebug

# macOS / Linux
./gradlew testDebugUnitTest lintDebug assembleDebug
```

在 Android Studio 配置 SDK，或通过 `ANDROID_HOME` / 本地 `local.properties` 指定路径。调试 APK 位于 `app/build/outputs/apk/debug/app-debug.apk`。不要提交本地 SDK 路径、签名密钥或缓存。

回归测试覆盖时间窗口、跨午夜、夏令时、监测状态恢复、亮屏宽限、过期广播及铃声回退。GitHub Actions 在推送和拉取请求时执行单元测试、Lint 和调试构建，保存 APK 与检查报告。设备验收步骤见 [docs/TESTING.md](docs/TESTING.md)。

## 限制与后续方向

- 亮屏来源尚未区分通知、来电和主动操作：**通知或来电导致持续亮屏超过 20 秒，仍会取消闹铃**。
- 厂商省电策略可能影响后台服务。建议允许通知，将应用电池策略设为“不限制”；系统强行停止后，需要重新打开并保存计划。
- 关机期间无法响铃；开机时已过期的预约会清除。所有铃声均不可用时只保留振动；系统音量与勿扰设置仍影响提醒。
- 当前以测试为主。单元测试和编译检查不能替代真机锁屏、重启和省电模式验收。
- 后续方向：加速度传感器、充电状态识别、穿戴设备睡眠监测。
