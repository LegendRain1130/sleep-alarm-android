## 验收步骤

单元测试验证纯业务逻辑，Lint 与编译验证 Android 接口和资源引用。以下系统行为需要在模拟器或真机执行；未执行时不得标为通过。建议覆盖 Android 12/12L、Android 13 以上及一台启用厂商省电策略的设备。

| 场景 | 操作 | 预期 |
| --- | --- | --- |
| 夜间开始前已熄屏 | 窗口开始设为两分钟后、睡眠时长一分钟，提前熄屏 | 窗口开始即安排一分钟后的闹铃 |
| 立即启动 | 当前处于窗口内，保存再熄屏 | 通知显示起床时间，到时播放并振动 |
| 锁屏亮起 | 预约后亮屏，保持锁定 | 立即撤销预约。窗口内再次熄屏从新时刻计时 |
| 窗口结束后响铃 | 监测已经开始时，设置窗口在两分钟后结束、睡眠时长三分钟，熄屏保持到响铃 | 窗口结束后已约闹铃在原定时刻响起 |
| 窗口结束后亮屏 | 重复跨窗口预约，窗口结束后亮屏再熄屏 | 原预约已撤销，窗口外保持无预约 |
| 服务重建 | 用调试工具结束进程，等待系统重建。不要使用系统设置里的“强行停止” | 熄屏时保留原预约。亮屏可撤销 |
| 改变窗口 | 修改为不包含当前时间的监测窗口 | 窗口外不创建新预约 |
| 关闭计划 | 关闭后等待原开始、结束和起床时间 | 不重开、不响铃 |
| 全天窗口 | 开始和结束设为相同时间，跨越该时间点 | 不取消已有预约 |
| 设备重启 | 预约后重启，并观察首次解锁后是否有亮屏事件 | 恢复未来预约，清除过期预约。恢复后亮屏可撤销 |
| 时间/时区 | 改变系统时间或时区 | 按新本地时间重排监测窗口 |
| 精确闹铃权限 | Android 12/12L 撤销权限再开启计划 | 显示授权入口，授权后返回应用可重新调度 |
| 锁屏停铃 | 允许闹铃通知与全屏提醒，熄屏到点后按“停止闹铃” | 显示停铃页，停止声音和振动并关闭页面 |
| 通知停铃 | 关闭全屏提醒权限，锁屏等待闹铃 | 系统闹铃通知提供“停止闹铃”，无需打开首页 |
| 调试版试响 | 首页点“试响”，从首页或通知停止 | 播放并停止试响，正式计划设置不变 |
| 正式版入口 | 安装正式 APK，打开首页并安排一次正常闹铃 | 首页隐藏试响，响铃时保留锁屏和通知停铃 |
| 失效铃声 | 删除自定义音频或撤销其访问权限 | 尝试默认系统铃声，停止按钮有效 |
| 停止播放 | 铃声准备期间或播放时停止 | 旧回调不重启声音；最长两分钟自动停止 |
| 后台与省电 | 熄屏进入省电/Doze 后测试预约 | 记录各设备实际响铃结果 |

通知或来电导致屏幕亮起时，也会立即撤销尚未响起的预约。
